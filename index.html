# Pizzaria Patrício - Changelog de Correções ## 🐛 Bugs Corrigidos ### 1. **Pedidos de Entrega não aparecem para o Entregador** ✅ **Problema Identificado:** - A função `delivery()` filtrava pedidos apenas por `status==='delivery'||status==='done'` - Quando um pedido era criado com `type='delivery'`, ele começava com `status='pending'` - O entregador nunca via os pedidos porque eles ainda estavam em "pending" ou "making" na cozinha **Solução Implementada:** ```javascript // ANTES (linha 926): function delivery(el){ const orders=S.get('pp_orders',[]).filter(o=>o.status==='delivery'||o.status==='done'); // ... } // DEPOIS: function delivery(el){ const orders=S.get('pp_orders',[]).filter(o=>o.type==='delivery'); // Agora mostra TODOS os pedidos de delivery, independente do status } ``` **Resultado:** Entregador agora vê todos os pedidos de delivery em qualquer estágio (pending, making, delivery, done) --- ### 2. **Mesas não ficam marcadas como Ocupadas** ✅ **Problema Identificado:** - Na função `submitOrder()` (linha 773), quando o tipo era "mesa", o pedido era criado mas **não salvava o `tableId`** - A função `tables()` procurava por `o.tableId===m.id`, mas esse campo nunca era preenchido - Resultado: mesas sempre apareciam como "Livres" **Solução Implementada:** ```javascript // ANTES (linha 782): orders.push({ id:nextId(orders), client, address:addr, type:orderType, items:cart.map(c=>({...c})), // ❌ Faltava: tableId total,payment:selectedPayment,obs,status:'pending',createdAt:now(),createdBy:currentUser.username }); // DEPOIS: const tableId=orderType==='mesa'?parseInt(document.getElementById('cart-table')?.value):null; const newOrder={ id:nextId(orders), client, address:addr, type:orderType, tableId:tableId, // ✅ Agora salva o ID da mesa items:cart.map(c=>({...c})), total,payment:selectedPayment,obs,status:'pending',createdAt:now(),createdBy:currentUser.username }; ``` **Resultado:** Mesas agora ficam marcadas como "Ocupadas" quando há um pedido ativo --- ### 3. **Número da Mesa não aparece nos Pedidos** ✅ **Problema Identificado:** - O campo `tableId` não existia nos pedidos, então não havia como exibir o número da mesa - Mesmo que existisse, as visualizações de pedidos não mostravam essa informação **Solução Implementada:** - Adicionado campo `tableId` ao objeto de pedido (vide bug #2) - Atualizado `viewOrder()` para exibir o número da mesa: ```javascript // ANTES:

${o.createdAt} — ${o.client}

// DEPOIS:

${o.createdAt} — ${o.client}${o.tableId?' (Mesa '+o.tableId+')':''}

``` - Atualizado `kitchenCard()` para exibir mesa nos pedidos da cozinha: ```javascript

#${o.id} — ${o.client}${o.tableId?' (Mesa '+o.tableId+')':''}${statusBadge(o.status)}

``` - Atualizado `orders()` para exibir mesa na lista de pedidos: ```javascript ${o.client}${o.tableId?' (Mesa '+o.tableId+')':''} ``` **Resultado:** Número da mesa agora aparece em todos os pedidos de mesa --- ## ✨ Novas Funcionalidades ### 4. **Adicionar Itens a Pedidos de Mesa Existentes** ✅ **Implementação:** - Adicionado botão "➕ Adicionar Itens" no modal de visualização de pedidos de mesa - Criada nova função `addItemsToTableOrder(orderId)` que: - Fecha o modal de visualização - Carrega o PDV com o carrinho vazio - Define o contexto para adicionar itens ao pedido existente - Mostra qual mesa e pedido está sendo editado - Criada função `addItemsToExistingOrder(orderId)` que: - Valida se há itens no carrinho - Adiciona os itens ao pedido existente - Atualiza o total do pedido - Salva as observações adicionais - Retorna à lista de pedidos **Como Usar:** 1.
